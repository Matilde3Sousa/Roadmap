## About The Project
This repository hosts an interactive tool for Image Segmentation tasks, such as Semantic Segmentation, Instance Segmentation and Panoptic Segmentation. It provides a dynamic visualization of 111 segmentation models, helping researchers and students quickly identify the best methods for their specific tasks.

### Overview
Image segmentation is a core task in computer vision that has evolved rapidly with many new models and methodologies. Navigating these developments can be challenging. This tool transforms a traditional literature review into an interactive mind map, letting you to:

* Explore model interconnections.
* Compare key metrics such as speed, average precision (AP), panoptic quality(PQ), and mean intersection over union (mIoU).
* Access the original research with just a click.

### Features
* Interactive Visualization: Easily filter and explore a network of segmentation models.
* Comprehensive Coverage: Based on 111 models, providing a broad view of the field.
* Performance Comparison: Directly compare models using various evaluation metrics.
* Research Accessibility: Quickly navigate to the original research articles for in-depth details.

### Development
This tool was initially developed as a static mind map for a literature review article. Due to the challenges in representing the numerous variables and intricate interconnections among models, we transitioned to an interactive solution. The final design uses libraries such as Cytoscape.js and WebCola.js to provide a dynamic visualization, enabling a clearer and more intuitive exploration of image segmentation models.
